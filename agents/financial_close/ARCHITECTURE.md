# Financial close architecture

1. Explicit fixture setup writes ledger, budget, and operations CSVs. The agent path never seeds missing finance files.
2. The planner model selects calculation tools from the allowlist. `CalculationToolbox.invoke` runs **only** those selected tools plus explicit mandatory/dependency tools (`ingest_and_normalize` and declared `TOOL_DEPENDENCIES`). If the model returns no valid tools, a **deterministic fallback** runs the full allowlist and is recorded separately on the draft (`model_selected_tools`, `dependency_tools`, `deterministic_fallback`).
3. `convert_gbp_usd` depends on ingest and aggregation. Dependency expansion places ingest before conversion, so a convert-first plan cannot replace FX results with a later ingest.
4. The writer receives short per-line `evidence_sentence` values only (Medicare claims 4000 unchanged, denials 14.0 to 22.6, and code-derived revenue direction below/above/matches budget; laboratory observed 19.26 versus budget-implied 18, qty 2500, variance 1.26, increase 3150). Lab caveat is not copied in that prefix; `_retain_lab_caveat` still attaches it on the rendered report. Nested `{evidence, hypothesis}` or a string prefix is accepted. Extra, missing, or non-string nested fields are rejected. A bounded 3-8 word explanation that is not an evidence copy is required; modal markers such as May are not required from the model. Medicare explanations must connect increased denials to collections or revenue shortfall. Laboratory explanations must connect higher supplier or unit price to expense increase. Volume, efficiency, and fluctuation claims are rejected. Accepted text is the exact evidence, then controlled `Hypothesis (not proved causality):`, then the raw explanation. That framing is presentation, not invented causality and not a fallback. Summary is at most 8 words. Truncated JSON is not repaired. `max_tokens` stays 320.
5. Writer and reviewer comments are grounded on complete numeric tokens and supplied identifiers. Canonical thousands grouping of a catalog value (`48,150` for `48150`) is ungrouped before Decimal matching. Invented magnitudes, sign changes, malformed grouping, and exponent forms stay rejected. The period catalog keeps full `YYYY-MM` for the existing period matcher and does not add standalone month or year, so October `10` cannot authorize an unsigned `10%` loss. Format-matching invented LED/UUID/hash/source refs are rejected unless they exist in the close facts. A writer `summary` string is collapsed to one logical line and checked with the same privacy and numeric rules.
6. `POST /financial-close/run` enqueues a Celery job and returns 202. Period/source `run_claims` plus `UNIQUE(period, version)` make parallel ticks produce one awaiting draft. Job claim uses a time-limited lease; the same owner cannot reenter while the lease is active. Expired leases may recover.
7. A valid awaiting draft is not superseded until a successor row is inserted in the same transaction. Rejection generates the successor first; if the writer fails, the parent remains awaiting and Tom retries the same approvals route. `distribute_approved` re-reads the persisted approved identity/version/hash/content before outbox insert.
8. Reports label known actual subtotals as incomplete. Complete budget net remains 390308 USD when budgets are complete. Figure lookup covers line actual/budget/percent, all eight operations metrics, laboratory 19.26 / 2500 / budget-implied 18 / unit-price variance 1.26 / increase 3150, FX, and consolidation. Laboratory support is omitted when the lab line is incomplete so a verified subset quantity is not divided into the full budget as a complete implied unit price. Consolidated and derived figures cite child `source_figure_id` links or concrete ledger/budget rows, not generic `line_id` placeholders. Result budget is revenue_budget_usd minus expense_budget_usd with native amounts converted to USD at briefing FX.
9. The tracker close page shows all seven report sections, revenue and expense actual/budget in the consolidated view, country/payer/currency/percent on line rows, contributing rows and hashes on source lookup, and reviewer comments on a revised report. Tom controls require the signed-in email, supervisor role, and revenue-cycle department together.
10. Live model proof requires a parsed planner selection (including convert_gbp_usd), used FX conversion results, and both Medicare and laboratory hypotheses accepted from the raw writer. Each accepted hypothesis must carry the exact evidence sentence, the controlled uncertainty frame, a 3-8 word raw explanation, and the per-line source driver. Default hypotheses, copied evidence alone, tautological revenue-fluctuation Medicare, efficiency/volume laboratory claims, nested non-string values, or a static tool list are not live evidence. `write_source` is `model` only when every relevant hypothesis parsed from the raw writer. The raw writer is not required to emit May. Local RAG remains n_ctx 2048 / max_tokens 320. Writer output is bounded JSON with one validated retry; truncated JSON is not repaired by inventing fields. Raw unvalidated writer text is not stored in SQLite or the audit log. Task 5 is not complete while a valid report can still present unsupported causes.
11. Approval and the seven internal report notices commit in one SQLite transaction. The same approval request can retry after a mid-outbox fault. Revised content still requires matching version and hash.
12. `actual_versus_budget` returns code-computed signed amount variance and percent_display. Missing or incomplete lines stay None. Report tables and figure lookup keep those signed values. Writer Medicare evidence adds qualitative actual-versus-budget direction without signed amounts. Writer prose copies labeled evidence and does not relabel observed 19.26 as budget-implied or treat Medicare denials as unchanged.

13. Rejection advances the durable period/source draft reference in the same transaction as the successor. Replay reconciles legacy stale references against the latest awaiting/approved revision with the exact facts digest; rejected parents cannot be returned as the current report.
14. The writer targets 3-8 words per explanation with a hard cap of 12 and a separate 8-word summary cap. A filled output template keeps evidence/status fixed. UI source lookup displays producing source_figure_id values, allowing reviewers to follow derived figures to their records.

15. Initial and revised awaiting drafts enqueue a Tom-only review_request with period/version/draft ID/content hash in the same SQLite transaction. A notice failure rolls back the draft. Review notices are distinct from the seven approved-report notices; replay cannot duplicate either. Fallback executive summaries derive missing files/lines and relevant deviations from CloseFacts.
